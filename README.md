# ArtikelTrainer 🇩🇪

Вебзастосунок для вивчення артиклів німецької мови.  
Розроблено на Python + Flask + SQLite + SQLAlchemy + Jinja2.

---

## Структура проєкту

```
artikel_trainer/
├── app.py                  ← головний файл (Flask + моделі + маршрути)
├── requirements.txt        ← залежності
├── artikel.db              ← база SQLite (створюється автоматично)
└── templates/
    ├── base.html           ← базовий шаблон (навігація, стилі)
    ├── login.html          ← сторінка входу
    ├── register.html       ← сторінка реєстрації
    ├── progress.html       ← екран прогресу
    ├── train.html          ← тренажер
    └── dictionary.html     ← словник з фільтрами
```

---

## Як запустити

### 1. Встановити Python 3.10+
Завантажте з https://python.org

### 2. Встановити залежності
```bash
pip install -r requirements.txt
```

### 3. Запустити застосунок
```bash
python app.py
```

### 4. Відкрити у браузері
```
http://127.0.0.1:5000
```

## Функціонал

- **Реєстрація / Вхід** — логін + пароль, збереження у SQLite
- **Прогрес** — статистика: вивчено слів, серія днів, точність, прогрес-бар
- **Тренажер** — адаптивний вибір слова за вагою (часті помилки → частіше показуються)
- **Словник** — 90+ слів, фільтри за артиклем (der/die/das) та категорією, пошук

---

## Моделі бази даних

| Таблиця  | Поля |
|----------|------|
| `User`   | id, login, password_hash, streak, last_day |
| `Word`   | id, article, german, ukrainian, category, suffix, hint |
| `Progress` | id, user_id, word_id, correct, total, last_seen |

---

## Адаптивний алгоритм

Формула ваги слова:
```
weight = (1 - success_rate) × 5 + min(days_since_seen, 7) × 0.5 + 0.5
```
- Нові слова → вага 10 (найвищий пріоритет)
- Слова з помилками → висока вага
- Давно не бачені → підвищена вага
